# Minor Project 05 – Advanced Excel Sales Analysis

## 📌 Project Overview

This project focuses on analyzing sales data using **Microsoft Excel**. The aim is to apply Excel formulas, data-cleaning techniques, lookup functions, pivot tables, and advanced analytical methods to extract meaningful insights from sales-related datasets.

## 🎯 Objectives

* Clean and organize raw datasets.
* Use Excel lookup and conditional functions.
* Analyze sales, revenue, and customer information.
* Evaluate product and sales representative performance.
* Calculate monthly and regional sales metrics.
* Apply advanced Excel formulas to solve business-related problems.
* Use pivot tables for data summarization and analysis.

## 📂 Datasets Included

The project contains information about:

* Orders
* Customers
* Products
* Sales Representatives
* Monthly Sales Targets

## 🛠️ Tools and Technologies

* Microsoft Excel
* Excel Formulas
* Pivot Tables
* Data Cleaning
* Data Analysis

## 📊 Key Concepts Covered

* Lookup Functions
* IF and Conditional Functions
* SUMIFS and COUNTIFS
* AVERAGEIFS
* Data Aggregation
* Sales Performance Analysis
* Regional Analysis
* Monthly Target Analysis
* Advanced Excel Functions

## 📁 Project Structure

* `Orders` – Order and transaction details
* `Customers` – Customer information
* `Products` – Product details
* `Sales_Reps` – Sales representative information
* `Targets` – Monthly sales targets
* `Q1_Lookups` – Lookup-related tasks
* `Q2_Cleaning` – Data-cleaning tasks
* `Q3_Aggregation` – Sales aggregation tasks
* `Q4_Pivot` – Pivot table analysis
* `Q5_Advanced` – Advanced Excel analysis

## 🚀 Learning Outcomes

Through this project, I developed practical skills in Excel-based data analysis, formula creation, data cleaning, sales reporting, and extracting business insights from structured datasets.
